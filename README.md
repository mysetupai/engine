# MySetup Engine

The engine behind MySetup: keeping your AI agent skills in sync across your computers, with version history, conflict handling and recoverable local changes.

**Open source is planned. The engine source has not been published here yet, and a licence and release date have not been announced.** This repository is its intended future home and a place to discuss the direction.

## What works today

The MySetup Mac app and CLI use the same Rust engine. You work with ordinary skill files; the engine handles managed sync, keeps both versions when changes conflict, and helps you recover earlier work.

[Explore MySetup Sync](https://mysetup.ai/sync)

## Where we’re heading

We want you to have more choice over:

- **Where you edit:** your editor, the Mac app, the website and your phone.
- **When changes are shared:** automatically, or after an explicit review and push.
- **What owns the shared history:** the MySetup service, or your private or public Git repository.
- **How computers connect:** managed cloud connections, SSH, or a private network such as Tailscale.

These describe our direction, not a list of released capabilities or a delivery schedule. Git-backed history and direct SSH/Tailscale connections are not available yet.
